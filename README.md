# Дипломная работа профессии «Python-разработчик с нуля»

## Backend приложения для социальной сети для обмена фотографиями

## Возможности приложения

### Создание публикаций
  Создавать публикации могут только зарегистрированные пользователи. Публикация будет иметь: текст, фото и время созданя. {POST http://127.0.0.1:8000//api/post/}

### Редактировать публикации
  Редактировать публикацию может только ее автор. {PATCH http://127.0.0.1:8000//api/post/1/}

### Оставлять комментарий к публикации
  Оставлять комментарии могут только зарегистрированные пользователи. {POST http://127.0.0.1:8000//api/comments/}

### Ставить лайки
  Ставить лайки могут только зарегистрированные пользователи. Один пользователь может поставить только один лайк к одной публикации. {POST http://127.0.0.1:8000//api/like/}

### GET запросы
  * Получить все публикации {GET http://127.0.0.1:8000//posts/}
  * Получить детальную информацию об одной публикации {GET http://127.0.0.1:8000//post/1/}

## Спецификация приложения
1. Приложение разработано на Django c использованием REST framework.
2. Создан интерфейс администратора средствами Django admin.
3. В качестве СУБД использован Postgresql.
